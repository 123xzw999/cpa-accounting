## 三大模块

每科都有三个入口：

### 1. 全知识点巧记
- 左侧章节导航，右侧知识点卡片
- 每个知识点三段式：**知识点 → 记忆口诀 → 口诀详解**
- 支持关键词搜索（标题 / 正文 / 口诀 / 详解 / 标签）、闪卡模式、收藏

### 2. 全题型精刷
- 题型筛选：单项选择题 / 多项选择题 / 主观题
- 章节筛选：按教材章节过滤
- 单选点选即判、多选确认后判、主观题对照标准答案
- 实时进度条

### 3. 历年真题考试
- **六科联考**：按官方顺序逐科作答，每科交卷后自动跳转下一科，六科全部完成点「全部交卷」才批改
- 顶部联考进度条显示六科完成状态
- 倒计时器
- 成绩页：六科各一张成绩卡 + 六科总分

## CPA 专属考试规则（与初级 / 中级不同）

- **不设判断题** —— 专业阶段只有单选、多选、主观题
- **多项选择题不设部分分** —— 全部选对得满分，**不答、错答、漏答均不得分**（初级/中级是选对比例给分）
- **主观题不自动判分** —— 客观题自动判分得出「客观题总分」；主观题对照标准答案自行估分后填入「主观题总分」；点击「计算总分」得出单科总分与六科总分

## 主观题透明书写模块

每道主观题下方有一个可书写区域：

- 点击即可直接书写，`contenteditable`，所见即所得
- 提供 **6 种书写颜色**：墨黑 / 深蓝 / 墨绿 / 绛红 / 紫 / 棕
- 字体不粗不细（`font-weight:400`），行距放宽，长时间书写不累
- 一键清空重写
- 写完后点「对照标准答案」查看参考答案、解析与易错点

主观题分值**精细到每个小题**：题目标注本题总分，小问逐条标注各自分值。

## 数据格式

```js
// 知识点库
window.KB_ACCOUNTING = {
  subject: "accounting", name: "会计",
  chapters: [{ id, name, points: [{ t, p, m, e, tags }] }]
  // t 标题  p 知识点  m 口诀  e 口诀详解  tags 标签
};

// 题库（type: single | multi | essay）
window.QB_ACCOUNTING = [
  { id, type: "single", stem, options: [4 项], answer: [0], point, analysis, chapter },
  { id, type: "multi",  stem, options: [4 项], answer: [0,2], point, analysis, chapter },
  { id, type: "essay",  kind: "计算分析题", score, stem,
    subs: [{ q, score }], answer, point, analysis, errors: [] }
];

// 真题卷
window.EXAM_ACCOUNTING = {
  subject, name, duration, objectiveScore, subjectiveScore,
  sections: [
    { name: "一、单项选择题", type: "single", perScore: 2, questions: [...] },
    { name: "三、计算分析题", type: "essay", questions: [{ score, subs, ... }] }
  ]
};
```
